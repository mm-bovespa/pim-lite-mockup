# PIM Lite — HCL Commerce Catalog Browser

A polished, fully interactive single-file HTML mockup of a **Product Information Management (PIM) Lite** tool for browsing HCL Commerce master catalogs.

## Features

- **Master Catalog selector** (Germany, Australia, Global)
- Expandable **category tree** with product counts
- Searchable, paginated **product table**
- Slide-over **product detail** panel with attributes, descriptions, and related SKUs
- **EN / DE** language toggle (mock content)
- Breadcrumbs, empty states, loading skeletons
- Keyboard shortcut: press `/` to focus search
- Clean modern UI (Inter font, light theme, micro-interactions)

## Technical

- Single self-contained `index.html`
- Tailwind CSS via CDN
- Vanilla JavaScript only
- All mock data embedded as JSON
- No build step required

## Purpose

Clickable prototype of a future internal PIM Lite application for HCL Commerce catalog exploration. All data is static mock data for demonstration purposes.
